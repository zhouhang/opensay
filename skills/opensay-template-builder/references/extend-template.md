# 根据真实分镜扩展已有模板

所有新模板和新增/修改片段先按[统一消费准入](consumer-admission.md)实现相同合同、运行入口与真实验证，再由库内 `builder-check` 判定承诺范围的制作就绪。

## 接单和问题分类

读取当前模板的源码、运行入口、能力声明和已认可的实际预览。读取本期冻结文案、实际声音/时间轴和唯一 `episode_plan.json`，通过请求中的镜头 ID 定位需求；不要只拿 SRT 自由重写本期视觉。

同时检查模板现有 BGM、SFX、声音事件和混音入口；按 [声音层交付](audio-design.md) 补齐受影响声音层与同步预览。原模板只有源片整条混音或静音模块时，记录为声音层缺口，不能当作已有纯净 BGM/SFX 能力。

校验本期和模板当前版本/哈希；若不一致，比较实际变化并更新交接，不能默默开发在另一个版本上。用户已有授权继续复用，不为未变输入重复确认。

对每个问题给出诊断：

| 问题 | 处理 |
| --- | --- |
| 已有模块可表达，先前选错 | 重做路由，不新增效果 |
| 模块合适，普通媒体缺失 | 获取和准确绑定素材；不能要求用户提供本可取得的普通 Logo |
| 真实操作/结果需要私有案例 | 明确具体镜头、输入/操作/结果所需素材；不要伪造产品界面 |
| 表达可行，但时长/事件错位 | 修复时序、阅读目标、模块状态转换；不改旁白速度 |
| 动作成立，但 BGM/SFX 缺失、盖住旁白或事件重复触发 | 修复声音素材、来源声明、事件绑定或 duck/fade；不靠复制原片混音混入旧旁白 |
| 当前模块不能表达核心关系 | 新增可复用模块或必要状态，不用换名/换字掩盖能力缺口 |

重复不是只看 ID：比较最近镜头的主体、构图和状态变化。聊天→办事等连续对照可保留相同场景以便理解；重复电视框/大卡仅换内容通常需要重新路由或扩展载体。不能为零重复而强塞无关动作。

## 写出最小开发任务

交接请求详见 `template-request.schema.json`。每镜至少有可定位的时间段、真实句子、视觉意图、当前问题和需要表达的变化。对相近需求合并成通用机制，例如输入→输出、前后对照、按任务取一份资料，而非车过桥/披萨专用动画。

从现有模板推导新模块的动态风格：字级和空间关系、线条/色板、角色比例与表情、缓动和形变、镜头运动和动作收束。尽量复用真实风格基础组件；不要只复用配色后重新做一套不协调的动画。可以在模板内增加独立模块入口，不强制改写整个旧工程或迁移渲染框架。

不要以源码章节中的 `sourcePhase` 数量当作模块覆盖率。新模块必须能独立初始化、接收本镜参数和目标时长、任意 seek、从其他模块切入并清理旧对象。能截到某一画面，不代表能独立制作完整镜头。

## 开发、实测、交回

1. 在本期工作目录保存开发前版本/哈希与待改范围；保留可回滚副本或版本提交，不覆盖用户其他修改。
2. 开发最小可复用模块，实际替换声明的文字、Logo、图片、视频和出镜参数。不存在的槽位不要声明支持。保留完整品牌名、数值单位和否定词。
3. 依原声音和可信词级证据（只有明确标注的测试预览才允许句级锚点）编排完整镜头，使用正式 renderer 实际播放。每个有效动作推进信息、焦点或状态；入场、背景呼吸和字幕更新不能冒充语义变化。缺词级证据不能宣称本期正式制作就绪；先补实际对齐，测试预览若采用句级锚点必须明确标注限制，不猜词时间。给受影响动作绑定模板 SFX，保留或明确调整 BGM 段落、响度和 duck/fade；对实际分离质量如实声明。
4. 把新模块与已有认可动作有声并排播放，检查视听风格；换一组内容验证复用，检查声明范围内的长短文案/时长/素材和真人模式，并对受影响旧模块及声音层做回归。单独试听素材，检查静音、换声音、暂停/跳时/复播没有叠播或旧声残留。
5. 技术检查、画面/听音自审完成后，更新本模板的源码、参数合同、`audio/` 素材和声音清单、`capability.json`、有声预览证据、版本和哈希。没有实际素材或尚未通过相应画面/声音检查的部分继续标缺口，不给全模板一律 `ready`，不把机器测量冒充听音自审。

交付回执保存在本期工作目录，包含：

- 请求/输入/模板修改前后的哈希、执行宿主和实际可得的模型信息；
- 新增/修复 module ID、表达范围、限制、独立运行与素材/时序实测结果，BGM/SFX 的来源/哈希、分离质量、事件/混音变更；
- 本期受影响 shot ID、新路由/参数/beats、包含实际旁白、BGM 与事件音效的完整动态草稿；
- 已有模块回归、剩余缺口、回滚位置，以及用户批准的真实状态。

更新本期同一 `episode_plan.json` 与人读编排表，不能交回孤立 Demo 后让 Sticker 重新凭空选镜头。返回同一次完整编排及完整正式动态预览审核，不新增逐模块或样片审批；当前版覆盖完整并确认后复用已审媒体进入 QC 和发布流程。模板准入不代表本期成片已获用户批准。
