# 模板声音层交付

创建参考模板时必读；扩展模板时用于审计已有声音层和验证受影响事件。目标是把参考片的声音设计变成可复用、可替换、可试听、可确定渲染的模板能力。无声动画、独立试听或整条源片混音均不能单独替代完整有声预览。

## 从参考中辨认声音

实际听取代表片段，记录 BGM 的音色、节拍/情绪、段落变化、持续区间和相对旁白的响度；记录 SFX 的源时间、时长、尾音及其对应的动作/语义事件。淡入淡出、duck 和响度数值区分“源片观察/测量”与“模板新增的混音值”。无法确定 BPM、原始曲名或某个音效来源就写 unknown，不靠画面或转写推断已听见的声音。参考本来没有某类声音时，保存可核验的 absent 状态，不强行生成。

区分四种角色：

| 角色 | 含义与限制 |
| --- | --- |
| `source_mix` | 原片混音，可能同时含旧旁白、BGM、SFX；只作参考对照，不能命名为纯净配乐 |
| `narration` | 本期原声或新文案的实际配音；不能循环/变速拼凑，也不能与旧旁白叠加 |
| `bgm` | 原始伴奏、分离伴奏或明确标注的同风格替代；包含残留声时写明程度 |
| `sfx` | 可按事件调用的音效；截取片段若混入底乐/人声，记录其混合属性和可用范围 |

优先寻找已明确来源的原始音乐/音效；否则从源片适当区间提取或本地分离。分离输出不等于纯净：检查旧旁白残留、乐器被削掉、泵音/金属伪影、音效误归到人声等。无法得到干净层时标出具体缺口和实际可用范围；可交带残留的参考层或同风格替代，但不得隐藏降级、臆造原曲名或宣称已完成原片声音复原。不能为了填满清单自行克隆原片说话人的声音。

## 模板内的资产与计划

声音素材存于模板唯一真源的 `audio/`，不放进 Skill 或另建全局音库。可沿用模板已有命名，最小交付包含：

- 可实际播放的 BGM 与代表性 SFX 文件，以及独立试听入口/文件；旁白和源片混音另标角色。
- 声音清单：资产 ID、模板内相对路径、角色、源 URL/文件哈希、源片起止时间、提取/分离方法及可得的模型/参数、输出哈希、时长/采样率/声道、质量检查与残留、权利/使用范围。分离或裁切衍生物继续关联原来源，不因处理就升级授权状态。
- 混音计划：旁白/BGM/SFX 资产绑定，时间偏移、片段、音量或增益、fade、duck 参数和事件对应关系；循环如确有必要须显式声明可循环范围与接缝测试，不能循环原旁白或不明混音。
- 声音能力与验证记录：真实支持的事件槽位、素材替换、分轨 mute/音量、限制、实际测量、听音状态和有声预览路径。

事件 SFX 绑定模块的 reveal/check/focus/merge 等可信语义 beats；记录 event ID、时间或 beat 引用、asset ID、offset、gain 与尾音处理。未出现的事件不播放，重复 seek/复播不累加一次性播放。BGM 连续承接按镜头/整段声音计划处理，不在每个模块初始化时无条件重新开始。

实时与离线使用同一音频计划、素材与时间基准。允许预先混成有哈希的音轨供两者共同播放，也可用同等结果的时间驱动音频图；只在离线导出后临时加声而实时预览仍静音，不算完成。音效尾音跨镜头、暂停、跳时、从其他模块切入时，必须按计划清理/重置而不残留。没有旁白的纯模板试听也应能开启/关闭 BGM 与 SFX。

## 混音与验收

把旁白可懂度作为混音判断依据，记录实际响度/真峰值、BGM 与旁白的层级、事件峰值、duck 区间和 fade。根据内容和音源实测选择参数，不把某套 LUFS/duck 值硬套为所有参考的风格；保留原速，不剪断词句或音效尾音来凑时长。

至少验证：

1. BGM 和代表 SFX 可独立试听，源片/分离/替代各自声明准确；纯净程度、混音残留和来源范围可追溯。
2. 实际播放完整音画预览，对照旁白、字幕、动作、音乐段落和 SFX 事件，检查人声可懂、尾音、突跳/接缝、削波与过响。机器测量、听音自审、用户批准分别记录；未实际听审就写 pending。
3. 更换内容和声音素材，检查事件位置、duck/fade、时长与重置；验证 mute/音量、暂停/跳时/复播不重复叠播，实时与离线均有声且时间一致。
4. 按模板当前版本/哈希保存声音清单、混音计划、测量与实际有声预览；扩展时回归受影响旧模块/声音事件。只有已测的槽位与模式才能写入能力声明。

源片音频及其分离衍生物在未明确取得所需权利前保留 `reference_only`，不能因入库、分离成功或机检通过就标 `production_eligible`。用户明确授权的本次本地参考样片可继续完成，不新增确认；该授权不自动变成跨集、公开发布或商业使用许可。交付时报告真实完成状态和具体缺口，不代填用户批准。

## 消费侧声音合同（2026-11-12 起，所有模板）

- 成片配乐从库根目录 `bgm/` 选。模板想指定默认曲目，在 `capability/usage-guide.v1.json` 写 `"sound":{"bgm_default":"<bgm/ 里的曲目名>"}`；不要把参考片提取的混音当默认曲。
- 每个模板交付 `audio/sfx-map.v1.json`（`opensay-sfx-map-v1`）：把本模板的事件名（`reveal-`、`focus`、`@cut`…）映射到库根 `sfx/` 音效包的 id 和相对响度，可按 `module` 细分。新增/修改模块引入新事件时同步补规则。没有这份映射，消费侧就没有音效。
- 映射只引用 `sfx/index.json` 里存在的 id。模板自带的 `reference_only` 音效不能被映射进成片；需要新的音色就向共享音效包补充有来源的文件。
- 准入时用真实内容渲染有声预览并听审映射后的效果；规范见库内 `.opensay/QUALITY.md`「音效」。
