# 从参考视频创建模板

**镜头怎么拆、做哪些模块、怎样才算还原，按 [从参考片逐镜复刻](replicate-reference.md) 执行；本文件只补充合同、声音与归档要求。** 所有新模板和新增/修改片段先按[统一消费准入](consumer-admission.md)实现相同合同、运行入口与真实验证，再由库内 `builder-check` 判定承诺范围的制作就绪。

## 输入与可观察依据

接受参考片链接、本地文件及用户偏好的片段/风格描述；用户未指定片段时，对整条参考片做逐镜清单（replicate-reference.md 第 1 步），不挑「代表性画面」，也不要求用户补填制作术语。先取得可实际观看的视频和声音，记录原始来源、文件哈希与实际片段时间。无法取得参考时说明具体缺口，不能靠封面或想象声称已拆解。

逐镜研究影响制作的内容：

- 信息层级、主次视觉对象、构图、素材和文字的关系；
- 字体、字号体系、描边、色板、阴影、形状与角色；
- 入场/退场、形变、缓动、运动轨迹、镜头运动、转场；
- 旁白触发哪次状态或焦点变化，何处留阅读时间，音效对应什么事件；
- BGM 的音色、节奏/段落变化、持续区间与旁白下的响度关系；事件音效的源片时刻、动作绑定、长短尾音，以及实际可听见的淡入淡出/duck；
- 真人如何与文字/素材共存；无真人时哪些构图仍成立。

每个结论关联参考片的时间点或帧，区分“观察到的动作”和“为模板新增的可复用表达”。把取值和动作规范保存在模板自己的风格文件中；不在 Skill 累积动态风格库。

声音是模板的一部分，不把源片整条混音直接当作可复用配乐。按 [声音层交付](audio-design.md) 分析原片每一镜的音效位置：事件音效进库根 `sfx/`（代码合成，打包时随模板分发），模板只交 `audio/sfx-map.v1.json`；配乐用库根 `bgm/`。源片提取/分离的声音只留在本期工作目录作对照。无法取得纯净层时如实保留缺口与可用的参考层；使用替代声音必须显式标注，不能只补一段无来源底乐就声称复现源片声音。

## 从风格到可复用模块

模块按逐镜清单里的镜头类型建立：一类原片镜头一个模块，覆盖表列出每一类的模块或缺口。表达关系（强调/定义、并列比较、因果流程、前后变化、输入输出、按需选取、品牌与素材展示、视频演示、真人加解释）写进模块的 intents 供消费侧选用，不用来决定做哪些模块。原片里没有、为口播通用性新增的片段单独标为「新增通用片段，非原片镜头」。只承诺实际实现并验证的类型。

每个模块使用模板现有或合适的渲染技术，但接口必须能够表达：

```text
module ID + 内容/素材参数 + 目标画幅/时长 + 真实语义 beats + 出镜方式
+ BGM/音效素材与混音/静音参数
→ 可确定渲染的当前时刻画面 / 音画同步完整镜头
```

时长分配包括入场、信息变化、阅读与退场；根据内容和语义安排，不把整个动画变速或机械循环延长。可延长的状态必须有真实可阅读/可观察目标。模块要有清理/重置机制，随机 seek 和切换模块均无残留。实时播放与离线渲染使用同一条实现路径。

BGM 可由模板默认层连续承接，SFX 按 reveal/check/focus/merge 等真实语义事件绑定；不能靠播放次数累计触发。声音支持素材替换、音量与 mute、开始/结束/淡入淡出和旁白 duck；实时预览与离线导出消费同一声音计划。源片旁白保持原速且不循环，不能通过播放整条原混音让旧旁白混入新文案。

素材采用明确的逐镜绑定：Logo 保留比例和透明度，图片/截图说明 contain/cover 及焦点，视频说明具体片段/帧率/播放规则。带真人的模板层可选，关闭时布局必须重排。不要把用户未提供的人脸或空框当默认主体。

## 验证与归档

至少完成下列实际检查，而非只填写声明：

- 按 replicate-reference.md 第 6 步，用构造的同类素材渲染每个模块，生成「原片 | 模块」对照报告；自动指标无标记且评审为「接近」才算通过；
- 换另一套内容/素材、合理长短文案和时长，检查容量、裁切、阅读及运动；
- 独立启动、重复播放、前后跳时、从其他模块切入，检查残留和随机寻址一致性；
- 按所声明的真人/无真人方式检查构图，只对已测试方式标验证；
- 单独试听 BGM、旁白和代表性 SFX，并记录分离残留/质量；有原声时与源片片段对照；
- 播放完整有声镜头，检验旁白、字幕、动作、BGM 段落、事件音效、duck/fade 是否对应，检查峰值/响度及音效尾音；只有机器测量时不冒充已听审；
- 在替换内容、暂停/跳时/复播、静音或更换音频素材后验证不重复叠播、无旧声残留，实时与离线结果一致。

真实预览、输入参数、源码/能力哈希、验证结果一起保存。静态图方便浏览，但不能取代动态预览。样片尚未批准时保持其真实状态，不将风格自审或成功渲染写成用户批准。

归档到 `opensay/<template>/`；源码/renderer、视听风格规范、`audio/sfx-map.v1.json`、能力声明、有声预览、必要依赖均在本模板目录（音效本体在库根 `sfx/`，配乐在库根 `bgm/`）。先留版本与回滚点，再写入当前库；不用新增全局 registry。未获相应使用授权的声音保留 `reference_only`，用户本次本地样片授权不自动扩展为商业发布或跨集授权。把新模板交给 Sticker 的模板选择阶段展示，后续按模板确认→完整编排及完整正式动态预览同轮审核→复用已审媒体/QC/发布流程执行；已有本次授权继续沿用，不因声音层或统一规范增加审批。
